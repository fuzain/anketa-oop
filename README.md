# anketa-oop

Обработчик анкет на классах (практическая работа 6, ООП).

## Модули

- `people.py` — классы `Person`, `Student`, `Teacher`, исключение `AnketaError`, функция `parse_line`
- `registry.py` — класс `Registry`: чтение файла, статистика, сохранение
- `main.py` — запуск и вывод результата
- `razminka/` — пять задач разминки

## Формат входного файла

    тип ; ФИО ; почта ; телефон ; группа или кафедра

Тип: `s` — студент, `t` — преподаватель. Пример — в `anketa.txt`.

## Запуск

    python3 main.py

Программа создаёт `ok.txt` (принятые анкеты) и `errors.txt` (брак с причинами).

## Тесты

    python -m pytest -q
